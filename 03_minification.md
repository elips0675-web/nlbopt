## Что осталось не минифицировано

`protobuf.js` — **268 КБ, 8 712 строк**, это файл ядра Битрикса (`/bitrix/js/pull/protobuf/protobuf.js`), а не шаблона. Настройка «минифицировать JS» его не берёт, потому что модуль Pull подключает свой файл напрямую.

Два пути:

1. **Правильный** — убрать Pull/protobuf с публичных страниц, если чат и уведомления не используются: `04_remove_unused_modules.md`.
2. **Обходной** — отдавать минифицированную копию через nginx-подмену, но это хрупко при обновлении ядра.

## Настройки в админке (для справки)

**Настройки → Настройки продукта → Настройки модуля «Главный» → Оптимизация CSS/JS**:

- ✅ Минифицировать JS-файлы
- ✅ Минифицировать CSS-файлы
- ✅ Объединять JS/CSS в один
- ✅ Переносить JS в конец страницы
- ✅ Использовать компрессию

## Чего не делать

- **Не включайте «Объединять JS в один» без проверки Jivo и форм.** Внешние виджеты и `data-skip-moving`-скрипты могут перестать инициализироваться.
- **Не минифицируйте `core.min.js` повторно** — он уже минифицирован, повторная обработка может сломать.
- **Не переносите `site.js`/`auth.js` в конец «насильно»**, если шаблон рассчитывает на их выполнение до DOMContentLoaded — сначала проверьте меню, слайдер, cookie-баннер и переключатель версии для слабовидящих.

## Проверка

```bash
# размеры JS на главной
curl -s https://nlb.by/ | grep -o 'src="[^"]*\.js[^"]*"' | wc -l

# в исходнике не должно быть "сырых" многострочных шаблонных бандлов
curl -s https://nlb.by/ | grep -o 'template_[a-f0-9]*_v1.js'
```

После изменений: **Настройки → Инструменты → Очистить кэш** (или удалить `/bitrix/cache/`).
